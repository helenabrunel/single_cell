# Presentation

Build slides and figures for presentations.

| Script | What it does |
|---|---|
| `01_concept_slide.py` | Draws the three-panel conceptual analysis slide. |
| `02_signatures_slide.py` | Draws the slide listing the 9 stemness signatures. |
| `03_analysis_and_results_slides.py` | Draws the analysis workflow and key results slides. |
| `04_analysis_and_results_slides_v2.py` | Second version of those slides. |
| `05_result_slides_per_cohort.py` | Draws one result slide per cohort. |
| `06_lab_meeting_figures.py` | Builds the lab meeting figures. |
| `07_lab_meeting_umaps.py` | Builds the lab meeting UMAP panels. |

See [SCRIPT_INDEX](../../docs/SCRIPT_INDEX.md) for the folder to run each script from.
